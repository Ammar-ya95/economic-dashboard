# Global Economic Dashboard

A responsive economic dashboard for the U.S., Texas, Saudi Arabia, and the global economy.

The site is designed for GitHub Pages and uses a scheduled GitHub Actions job to refresh public economic data every day. Daily series update daily when a new observation is available; monthly, quarterly, and annual indicators continue to show the latest official observation until the next release.

## Data sources
The automated refresh uses public endpoints from sources such as FRED/Federal Reserve and the World Bank. Every indicator in the dashboard displays its observation date, frequency, and source.
